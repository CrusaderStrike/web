# web
crusaderstrike.com website and guild sites

## Tests

Playwright end-to-end tests live in `tests/e2e/`; see `tests/e2e/README.md` with the site served on http://localhost:8765. Suites: `gear.e2e.js`, `profile.e2e.js`, `rankings.e2e.js`, `signin.e2e.js`.
